Manage Lists
Locations & Departments used when provisioning a user — rename anytime without breaking existing records
Locations
Each location has a permanent internal ID (used for scoping and reporting) and a display name you can rename anytime — for example, two branches can both show as "Gurgaon" while staying separate underneath.
Departments
Departments are informational only — renaming an entry changes what's offered for new users going forward, but doesn't change anyone's existing record.
Teams
Each team belongs to one location and has one or more Team Leaders. To put a Sales Rep on a team, edit that person's row in User Management — this screen only manages the team itself (its name and who leads it). A person must already have the "Team Leader" role (set in User Management) before they can be picked here as a team's leader.
